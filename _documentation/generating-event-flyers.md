The Event Flyer Generator creates professional, AI-generated flyers for your events using the information already entered in the event form.

## Creating a Flyer for a Specific Event

### Step 1: Open the event editor and click "Generate AI Flyer"

Navigate to the event you want to create a flyer for, then click the blue "Generate AI Flyer" button in the Event Flyer section.

<figure>
<picture>
<img src="/assets/images/docs/generating-event-flyers/screenshot-01.png" class="announcement-img-lightbox">
</picture>
<figcaption>Event Flyer section with Generate AI Flyer button</figcaption>
</figure>

### Step 2: Review and edit the flyer content

The system analyzes your event details and displays them in the flyer content editor. Edit the text as needed—each line becomes a separate element on the flyer. Also choose your preferred visual style from the dropdown menu (MS Word is selected by default). Then click "Generate Flyer" and wait up to a minute for generation to complete.

<figure>
<picture>
<img src="/assets/images/docs/generating-event-flyers/screenshot-02.png" class="announcement-img-lightbox">
</picture>
<figcaption>Flyer content editor showing editable text and style options</figcaption>
</figure>

### Step 3: Review your flyer and make revisions if needed

Once generated, you can review the flyer preview and either use it immediately or generate up to 3 revisions by changing the style or adding editing instructions. Once you're satisfied with the flyer, click "Use This Flyer" to attach it to your event. It will then automatically update on your council website and newsletter.

## Editing an Existing Flyer

After a flyer has been attached to an event, you can make changes by clicking the "Edit" button in the Event Flyer section. You can change the style, add editing instructions describing what changes you want, or both, then generate a revision.

## Generating a Standalone Flyer

You can also generate a flyer without attaching it to a specific event. This is useful for creating custom flyers for promotions or announcements.

### Step 1: Navigate to Events Overview and click "Generate Flyer"

From the Events Overview page, click the blue "Generate Flyer" button in the Events Actions section to start creating a custom standalone flyer.

<figure>
<picture>
<img src="/assets/images/docs/generating-event-flyers/screenshot-06.png" class="announcement-img-lightbox">
</picture>
<figcaption>Events Overview page with Generate Flyer button in the Events Actions section</figcaption>
</figure>

### Step 2: Follow the flyer generation process

Follow the same process as event-attached flyers: edit content, select a style, generate, and review. The main difference is that when you're ready to use the flyer, it will download directly to your device instead of being attached to an event.

## Tips

- **Complete event details first** - The AI uses your event name, description, date, time, and location to create the flyer
- **Keep content concise** - Each line in the flyer content becomes a separate element, so shorter lines work better
- **Choose the right style** - Consider your event's tone and audience when selecting a visual style
- **Use revisions wisely** - You can generate up to 3 versions, so experiment with different styles and modifications
- **Remember to save** - Click "Submit Edits" at the bottom of the event edit page to save all changes
