## Introduction

The Event Flyer Generator allows council administrators to create professional, AI-generated flyers for their events using the information already entered in the event form.

## Accessing the Flyer Generator

To generate a flyer for an event, you must first navigate to an existing event's edit page.

**Steps:**
1. Navigate to the Events page from the main menu
2. Select an event to edit
3. Scroll down to the "Event Flyer" section

## Starting Flyer Generation

In the Event Flyer section, you have two options for adding a flyer:
- **Select Flyer** - Upload a pre-designed flyer manually
- **Generate AI Flyer** - Automatically create a flyer using AI

**Steps:**
1. Locate the "Event Flyer" section on the event edit page
2. Click the blue "Generate AI Flyer" button

![Event Flyer section with Generate AI Flyer button](/assets/images/docs/generating-event-flyers/screenshot-01.png)
*The Event Flyer section provides options to upload an existing flyer or generate one with AI*

## Reviewing Flyer Content

After clicking "Generate AI Flyer," the system analyzes your event details and extracts key information for the flyer. The flyer content editor appears with:
- **Flyer Content** - Editable text area with event details (one item per line)
- **Flyer Style** - Six visual design options to choose from

**Available Flyer Styles:**
- **MS Word** - Simple, functional design resembling a typical Microsoft Word flyer template
- **Rustic** - Warm, traditional, timeless aesthetic with natural materials and cozy ambiance
- **Classic Formal** - Elegant, traditional design with ornate details and formal presentation
- **Cartoony** - Fun, playful design with illustrated elements and vibrant cartoon aesthetics
- **Vintage/Retro** - Nostalgic design inspired by mid-century aesthetics and classic poster styles
- **Chalkboard** - Casual, friendly design resembling hand-drawn café chalkboard menus

![Flyer content editor showing editable text and style options](/assets/images/docs/generating-event-flyers/screenshot-02.png)
*Review and edit the flyer content before generation. Each line becomes a separate element on the flyer.*

**Important:** You can edit the flyer content before generating. Remove any lines you don't want to appear on the flyer, or add additional information.

## Generating the Flyer

**Steps:**
1. Review and edit the flyer content as needed
2. Select your preferred flyer style (MS Word is selected by default)
3. Click the blue "Generate Flyer" button at the bottom
4. Wait for the flyer to be generated (this may take up to a minute)

## Reviewing and Refining Your Flyer

Once generation is complete, you'll see a preview of your flyer with several options:

![Generated flyer preview with refinement options](/assets/images/docs/generating-event-flyers/screenshot-03.png)
*The generated flyer preview shows your event information in the selected style*

**Available Actions:**
- **Generate Revision** - Create a new version with different style or modifications
  - Change the style from the dropdown menu
  - Add optional editing instructions (e.g., "Make the text larger," "Use brighter colors")
- **Use This Flyer** - Accept the current design and apply it to your event
- **Cancel** - Discard the flyer and return to the event edit page

**Note:** You have up to 3 generations to refine your flyer. The system tracks which generation you're on (e.g., "Generation 1 of 3").

## Applying the Flyer to Your Event

**Steps:**
1. Review the generated flyer preview
2. If satisfied, click the blue "Use This Flyer" button
3. The system returns you to the event edit page with the flyer attached

![Event edit page showing the attached flyer with Download, Edit, and Remove buttons](/assets/images/docs/generating-event-flyers/screenshot-04.png)
*The generated flyer now appears in the Event Flyer section with options to download, edit, or remove it*

Once the flyer is attached, you'll see:
- A thumbnail preview of the flyer
- Alt text describing the flyer
- Upload timestamp
- **Download** button - Downloads the flyer as an image file
- **Edit** button - Opens the flyer editor to make revisions or change the style
- **Remove** button - Deletes the flyer from the event

**Important:** Remember to click the "Submit Edits" button at the bottom of the page to save all changes to your event, including the newly generated flyer.

## Editing an Existing Flyer

After a flyer has been generated or uploaded, you can make changes to it using the Edit button.

**Steps:**
1. Navigate to the event's edit page
2. In the "Event Flyer" section, click the blue **Edit** button
3. The flyer editor opens, showing your current flyer preview
4. Choose from the following options:
   - **Change the Style** - Select a different visual design from the style dropdown
   - **Add Editing Instructions** - Describe what changes you want (e.g., "Make the text larger," "Use brighter colors")
   - **Do Both** - Change the style AND add editing instructions for additional customization

![Flyer editor showing options to revise the design](/assets/images/docs/generating-event-flyers/screenshot-05.png)
*The flyer editor allows you to change the visual style or add editing instructions for revisions*

**Available Actions:**
- **Generate Revision** - Create a new version based on your style choice and/or editing instructions
- **Use This Flyer** - Accept the current flyer (if you made a revision, this applies the new version)
- **Cancel** - Return to the event edit page without saving changes

**Note:** You can generate up to 3 versions total of a flyer. The counter shows which generation you're currently on (e.g., "Generation 1 of 3").

### Tips for Effective Revisions

- **Only change the style** if you're happy with the layout but want a different visual aesthetic
- **Add editing instructions** if you want specific changes to the content layout or design elements
- **Use both options** for maximum customization—change style and request specific adjustments in one revision
- **Save your edits** by clicking "Submit Edits" at the bottom of the event edit page after applying your revised flyer

## Tips for Best Results

- **Complete event details first** - The AI uses your event name, description, date, time, and location to create the flyer
- **Keep content concise** - Each line in the flyer content becomes a separate element, so shorter lines work better
- **Choose the right style** - Consider your event's tone and audience when selecting a visual style
- **Use revisions wisely** - You can generate up to 3 versions, so experiment with different styles and modifications
- **Preview before finalizing** - Always review the generated flyer before clicking "Use This Flyer"
